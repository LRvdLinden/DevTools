App Store Connect는 iOS, iPadOS, macOS 및 tvOS 앱을 Homey로 가져옵니다.

App Store Connect 계정의 모든 앱을 기기로 추가하고 다음을 확인하세요:
• 어제, 최근 7일, 최근 30일 및 전체 기간 다운로드
• 최근 30일간의 업데이트 및 수익
• App Store 상태(라이브, 심사 대기 중, 심사 중, 배포 준비 완료, 출시 대기 중, 거부됨)
• 라이브 버전, 다음 버전 및 최신 TestFlight 빌드
• 평점 및 평가 수

"모든 앱" 기기는 전체 포트폴리오의 합계를 보여 줍니다: 총 다운로드, 라이브 앱, 심사 중인 앱 및 확인이 필요한 앱.

Flow
• 언제: 상태 변경, App Review 진입, 거부됨, 배포 준비 완료, 출시 대기 중, 새 라이브 버전, 새 빌드, 빌드 처리 완료, 새 고객 리뷰, 평점 변경, 새 다운로드 수치, 다운로드 감소
• 그리고: 앱이 라이브 상태, App Review 중, 새 버전 진행 중, 다운로드가 특정 수 초과, 평점이 특정 값 초과, 라이브 버전이 X일보다 오래됨
• 그러면: 새로 고침, 승인된 버전 출시, 고객 리뷰에 답글 달기

대시보드 위젯
다운로드(단일 앱 또는 모든 앱, Insights 스타일 차트 포함), 인기 앱, 심사 및 상태 – DevTools iPhone 앱과 동일한 디자인입니다.

설정: App Store Connect API 팀 키(관리 역할)를 생성하고 앱 설정에 Issuer ID, Key ID 및 .p8 키를 붙여 넣으세요. 다운로드를 보려면 공급업체 번호를 추가하세요. 설정에 단계별 가이드가 포함되어 있습니다.

API 키는 사용자의 Homey에만 저장됩니다. 이 앱은 Apple Inc.와 관련이 없습니다.
