Connecting your account

  1. In App Store Connect go to Users and Access → Integrations → App Store Connect API → Team Keys.
  2. Tap +, enter a name (e.g. “DevTools”) and choose the Admin role. Tap Generate.
  3. Copy the Issuer ID shown above the list of keys.
  4. Download the key file AuthKey_XXXXXXXXXX.p8 (Apple only allows this once) and save it to the Files app on your iPhone, e.g. via AirDrop or iCloud Drive.
  5. In DevTools tap Connect App Store Connect, enter the Issuer ID and choose the .p8 file – the Key ID is filled in automatically.
  6. For downloads and proceeds, enter your vendor number: App Store Connect → Business, the 8-digit number next to your address.

DevTools also contains this guide: Account → Guide.

Troubleshooting

  • 401 – Authentication failed: the Issuer ID or Key ID is wrong, the .p8 belongs to another key, or the key was revoked.
  • 403 – No access: the key's role is too limited. Use a key with the Admin role.
  • No downloads: the vendor number is missing, the key lacks the Sales/Finance role, or Apple has not published the report yet (about one day delay).
  • Apple Watch shows no data: open DevTools on your iPhone once, then tap Fetch on the watch.
