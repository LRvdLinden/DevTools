DevTools is a companion app for developers that uses the official App Store Connect API (https://developer.apple.com/documentation/appstoreconnectapi). It has no server and no user accounts of its own: the user adds their own App Store Connect API team key (Issuer ID, Key ID and .p8 private key), which is stored only in the device Keychain.

HOW TO TEST
1. Launch the app, tap "Link App Store Connect" (Koppel App Store Connect).
2. Enter the Issuer ID and Key ID below and import the attached/linked .p8 file.
3. Optionally enter the vendor number below to see downloads and proceeds.

Issuer ID: <ISSUER_ID>
Key ID: <KEY_ID>
.p8 key: <LINK TO KEY FILE, e.g. a shared iCloud Drive link>
Vendor number: <VENDOR_NUMBER>

The key has the "Developer" role, so it can read apps, builds and TestFlight but cannot make changes or see sales. The key will be revoked after review.

The Apple Watch app and the widgets show the data that the iPhone app loaded; open the iPhone app first.

Encryption: the app only uses standard HTTPS and Apple's CryptoKit to sign the API token (exempt).
